# CivicDesk

A platform for reporting local problems and managing them through
municipalities and public institutions.

## Structure

- backend/ — ASP.NET Core Web API with PostgreSQL and EF Core.
- frontend/ — Frontend application, to be added.
- docs/ — Project documentation, to be added.

## Backend projects

- CivicDesk.Domain — Entities and domain rules.
- CivicDesk.Repository — Database configuration and repositories.
- CivicDesk.Service — Application workflows and services.
- CivicDesk.Web — API endpoints and application setup.
